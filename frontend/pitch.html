Core Technical Highlights

Stateful Interview Agent

后端维护 session、current question 和 turns，避免每轮面试都变成无记忆的一次性聊天。

RAG With Evaluation

不仅使用向量检索，还通过 Hit Rate、Recall@1/3/5、misses 和 category summary 衡量召回质量。

Tool Router

根据用户意图选择 Ask RAG、Retrieval Eval、Weakness Report 或 Logs，形成可测试的 Agent 工具调用闭环。

Structured Scoring

解析 LLM evaluation JSON，把分数、优点、弱点和建议渲染成可读评分卡，而不是把原始 JSON 扔给用户。

Product-Grade Data Path

本地默认 SQLite，生产支持 PostgreSQL，并通过 Alembic 管理 schema migrations。

Engineering Evidence

后端 pytest、Playwright E2E、GitHub Actions、Docker、Railway/Vercel 部署和日志排障文档共同构成工程证据。
